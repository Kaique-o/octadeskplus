# relatorios de validacao

```text
reports/
├── architecture/    # validacoes estruturais e de contratos
├── quality/         # testes, Lighthouse e qualidade
└── releases/        # evidencias especificas de cada versao
```

Cada versao deve possuir sua propria pasta em `releases/<versao>/`.

Relatorios novos devem registrar:

- escopo validado;
- comandos executados;
- resultado real;
- limitacoes do ambiente;
- pendencias externas.
